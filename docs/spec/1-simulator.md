# 第一階層　シミュレーターとしての Janus-POS

実機の POS には存在せず、ブラウザで動くシミュレーターだから持っているものをまとめる。ここに書いたものは第二階層の原則（たとえば「覆いかぶさるポップアップを出さない」）の対象外とする。

## 画面の構成

- **S-01 ページの配置**：ヘッダー「Janus POS」、左 2/3 に Bell エリア（上）とレジ 1・レジ 2、右 1/3 に Item と Wallet。フッターは著作権表示だけ。
- **S-02 一台のレジ**：スタッフ側画面と顧客側画面を並べる。「スタッフ側」「お客様側」の見出しは画面の外に小さく出す。
- **S-03 入金・出金ボックス**：顧客側画面の下に置く（自動釣銭機の出し入れ口は売り場側にあるため）。入金ボックスは数字を打って Enter で入れられ、現金払い中の Enter は「投入おわり」の近道。出金ボックスはクリックで取り出す。

## 操作の代わり

- **S-04 Item**：商品をレジ画面へドラッグすると、その側でバーコードを読んだことになる。分類は日配食品・加工食品・非食品・サービス・カトラリー＆レジ袋。FF は Item に置かず、レジ画面の FF タブから登録する。
- **S-05 Wallet**：紙幣・硬貨を入金ボックスへ落とすと投入、ポイントカード・電子マネー・クレジットカード・バーコード決済を落とすと読み取り（かざす）になる。実在のサービス名は使わない。
- **S-06 ドラッグの受け口**：ドラッグ中に受け付ける場所は枠が破線になる（太さは変えない）。
- **S-07 スタッフのログイン**：実機ではスタッフバーコードを読む。シミュレーターでは各レジの見出しの右端にある「スタッフ」の選択欄で代用する。

## 知らせ

- **S-08 ブラウザアラート**：買い物点数の上限（10 点、`MAX_ITEMS`）を超えて登録しようとしたときに `alert()` で知らせる。表示エリアに合わせたシミュレーターだけの制約で、実機では起きない。
- **S-09 販売個数の上限のアラート**：オーナーが決めた「1回のお会計で N 個まで」を超えたときも `alert()` で知らせる。※実機での知らせ方は未定（第三階層の棚卸しで扱う）。
- **S-10 トースト**：レジ画面の外（年確ルールの設定・店舗全体の操作）の結果だけトーストで出す。レジ画面には出さない。

## Bell エリア

- **S-11 Bell の端末**：据え付け端末（常に ON）、可搬性端末、ストアコンピューターを並べる。後の二つは ⚙ の設定で OFF にできる。タイルには鳴動中・呼び鈴 OFF のときだけ状態を出す。
- **S-12 呼び出しの音とランプ**：Bell は呼び出しボタンを押している間だけ鳴る。レジ側は音を出さず、レジ名の横のランプで知らせ、放置が長いほど速く点滅する。

## 設定

- **S-13 商品ルール設定**：Item の見出しの ⚙ から開く。年確・販売個数の上限・税率を商品ごとに決める。オーナーの認証が要る。法定の年齢（酒・たばこ 20 歳）は変えられない。

## モバイル表示

- **S-14 幅 760px 以下**：Bell と両方のレジを残し、Item と Wallet は隠す。スタッフ側と顧客側はスワイプで切り替え、操作できる側のタブを 2/3 幅にする。操作する側が変わると自動でその側へ移る。
- **S-15 長押し**：レジ画面の長押し（500ms）で Item の商品を、入金ボックスの長押しで Wallet の支払いを選ぶ。ヘッダーと呼び出しボタンの長押しでは開かない。

## 時間

- **S-16 時間の定数**：タッチロック 1 秒、取引完了のあいさつ 3 秒、無操作での取引中止 5 分、取引中止の長押し 1.5 秒。実機に合わせて変えてよい値として扱う。
